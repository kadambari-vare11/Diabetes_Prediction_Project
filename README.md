# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person is diabetic based on medical attributes using Machine Learning. The application is built with Python and Streamlit for an interactive user interface.

---

## 🚀 Features
- Predicts diabetes risk
- User-friendly Streamlit web application
- Data preprocessing and feature scaling
- Trained Machine Learning model
- Fast and accurate predictions

---

---

## 📊 Dataset
- Dataset: Pima Indians Diabetes Dataset
- Features:
  - Pregnancies
  - Glucose
  - Blood Pressure
  - Skin Thickness
  - Insulin
  - BMI
  - Diabetes Pedigree Function
  - Age

---

## 🤖 Machine Learning Model
- Support Vector Machine (SVM)

---

## 📈 Output
The application predicts whether the patient is:
- Diabetic
- Non-Diabetic
